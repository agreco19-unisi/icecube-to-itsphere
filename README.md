# From IceCube to IT-Sphere

**A Hybrid Quantum–Classical Graph Neural Network for Banking IT Root Cause Analysis**

Accepted as a poster at the **IEEE International Conference on Quantum Computing and Engineering (QCE26)** — IEEE Quantum Week · Toronto · September 2026.

**→ Project page: [agreco19-unisi.github.io/icecube-to-itsphere](https://agreco19-unisi.github.io/icecube-to-itsphere/)**

## About

The work transfers a reconstruction method from neutrino astrophysics to IT operations. In the IceCube detector, the task is to find the interaction vertex among thousands of photon hits. In banking IT operations, the task is to find the one root-cause alarm hidden in a flood of correlated alarms. Same problem shape — so the same graph neural network backbone (DynEdge), extended with a compact variational quantum circuit executed on IBM quantum hardware, is applied to production alarm data.
